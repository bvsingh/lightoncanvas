Before you write

The user manual covers the whole app, and the features and quick start page has a two-minute walkthrough. If it is one of the below, the answer is here.

Common questions

My publish says “Galleria can’t write to /var/www/…”

The folder belongs to another user on the server. Either publish somewhere your SSH user owns, or ask your host to change the folder’s ownership. Test Connection in the server settings will tell you before you upload anything.

The images uploaded but the website shows broken images

Almost always file permissions on the server. Galleria sets published files to be world-readable, but some hosts override that. Check that the web server user can read the folder you published into.

Galleria says my server’s identity has changed

That means the server’s SSH host key is different from the one Galleria remembered. Usually the server was rebuilt or migrated — but it can also mean you are connecting to something that is not your server, which is why Galleria stops rather than asking you to click past it. If you know why it changed, open the destination menu, choose Manage Destinations… and use Forget this server’s identity.

Some of my photographs show as Missing

Galleria references your originals where they live rather than copying them, so a Missing photograph means the file moved, was deleted, or is on a drive that is not connected. Reconnect the drive, or use the relink option. To make a gallery self-contained in future, use File ▸ Consolidate Originals…

I paid but Galleria still asks me to

Open Galleria ▸ Settings and press Restore Purchase. If that does not do it, check you are signed in to the App Store with the Apple Account you bought it with. If it still does not, write to me — that is a bug and I want to know.

Should I subscribe or buy it outright?

Purely arithmetic: $29.99 once is about three years of the $9.99 subscription. If you expect to keep using Galleria for longer than that, buy it outright. They unlock exactly the same things.

What happens to my galleries if I stop paying?

They keep opening, and stay editable. What stops is producing new exports and publishes. Consolidate Originals is never restricted, so you can always copy every photograph back out at full resolution, and anything already published stays on your server untouched.

Can I use it without a server?

Yes. Export to a folder instead. The result opens straight from disk — double-click index.html — and you can upload it anywhere, including hosts that only take a drag-and-drop.

Does it work with my raw files?

If macOS can read the format, Galleria can. It reads the embedded preview or renders the raw, and publishes JPEG or AVIF copies at the sizes you choose. Your raw files are never modified.

Reporting a problem

Include these and it will be fixed much faster:

  • What you did, what happened, and what you expected instead

  • Your macOS version and your Galleria version (Galleria ▸ About Galleria)

  • Whether it was an export to a folder or a publish to a server

  • The exact wording of any message — a screenshot is ideal

Send it to galleria@lightoncanvas.com.

Refunds

Purchases go through Apple, so refunds do too — request one at reportaproblem.apple.com. I cannot issue one directly, but if something is wrong with the app I would rather hear about it and fix it.
